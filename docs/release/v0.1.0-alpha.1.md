# LumiSync v0.1.0-alpha.1

This developer preview publishes the tested Swift core and CLI harness for Apple Silicon Macs running macOS 14 or later.

## Included

- Brightness curves and presets
- Synchronization priority state machine
- Display source selection
- External keyboard activity policy
- Transition smoothing
- Versioned preferences
- Native App and privileged Helper interface scaffolds
- CI, release gates, and Homebrew distribution metadata

## Install

```bash
brew install Dee-0503/LumiSync/lumisync
lumisync
```

Expected output:

```text
LumiSync 0.1.0
```

## Important limitation

This alpha release is a developer preview of the core and CLI harness. It does **not** yet install a working menu-bar App or control keyboard backlight hardware. The production App remains blocked by the documented keyboard-backlight feasibility test, complete Xcode, Developer ID signing, notarization credentials, and a signed App artifact.
