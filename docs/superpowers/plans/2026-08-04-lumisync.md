# LumiSync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build LumiSync, a macOS menu-bar brightness-sync utility for Apple Silicon MacBooks, with a testable core engine, native app scaffold, Helper boundary, packaging automation, and Homebrew Cask release path.

**Architecture:** Implement the deterministic, hardware-independent Sync Engine first as a Swift package with tests. Add macOS adapters and UI behind protocols so hardware feasibility gates do not block core correctness. Treat keyboard-backlight control, signing, notarization, GitHub remote creation, and Homebrew release as explicit gates with verifiable commands.

**Tech Stack:** Swift 6.2, Swift Package Manager, SwiftUI/AppKit, XCTest, CoreGraphics, IOKit, ServiceManagement, XPC, GitHub CLI, Homebrew Cask.

## Global Constraints

- Minimum OS: macOS 14 Sonoma.
- Hardware target: Apple Silicon MacBook with built-in backlit keyboard.
- Distribution target: signed and notarized GitHub release installed via Homebrew Cask.
- Input Monitoring is mandatory for normal operation.
- Helper is signed, minimal privilege, and only reads/writes built-in keyboard backlight.
- External display brightness is read-only in version 1.
- Do not persist key contents, input sequences, display contents, user documents, telemetry, or secrets.
- Default curve: Comfort.
- Login launch is enabled by default only after onboarding and Helper installation complete.
- Current environment gates discovered on 2026-08-04: `/Applications/Xcode.app` is absent, code-signing identities are absent, and no Git remote is configured. Full notarized release and remote push cannot be honestly completed until these are resolved.
